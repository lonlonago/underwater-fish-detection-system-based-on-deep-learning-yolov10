# Underwater fish detection system based on deep learning YOLOv10

## Body

Based on the YOLOv10 deep learning algorithm, this project aims to build an efficient and accurate underwater fish detection system. The system can detect fish in real-time images or videos and output detection results. Through training and optimization of the model, the system can accurately identify fish in complex underwater environments, meeting the needs of marine ecological research and fishery resource management.
